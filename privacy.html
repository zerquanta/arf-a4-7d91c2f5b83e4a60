Privacy

I PDF restano sul dispositivo. Amazon Return Fixer è una PWA statica e non possiede un backend, un database o un endpoint di upload.

I PDF selezionati o ricevuti tramite il menu Condividi vengono letti e trasformati nel browser. Per i file condivisi, il service worker usa temporaneamente la Cache Storage locale del browser per passare il PDF alla schermata dell'app; dopo l'apertura la copia temporanea viene rimossa.

PDF.js 6.4.299 e pdf-lib 1.17.1 sono caricati da CDN pubbliche con versione fissata e possono essere memorizzati nella cache del browser. I CDN ricevono la normale richiesta dei file JavaScript, ma non ricevono il contenuto dei PDF.

I link Amazon vengono analizzati localmente per estrarre la destinazione. Query e token non vengono inclusi nel debug. Il bookmarklet viene eseguito direttamente nella pagina Amazon già aperta e non invia cookie, password o etichette a Return Fixer.

Il sito usa noindex e robots.txt per scoraggiare l'indicizzazione. Questo non equivale a un'autenticazione: un sito GitHub Pages resta accessibile a chi conosce l'URL.
