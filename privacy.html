Privacy

Amazon Return Fixer è una PWA statica: i PDF selezionati vengono letti e trasformati nel browser del dispositivo. Il progetto non contiene backend, API, database o endpoint di upload.

Le librerie PDF JavaScript sono caricate da CDN pubbliche con versioni fissate. I CDN ricevono la normale richiesta dei file JavaScript (come per qualunque risorsa web), ma il contenuto dei PDF non viene inviato ai CDN.

I link Amazon vengono analizzati localmente per estrarre l'URL di destinazione. Il bookmarklet viene eseguito nella pagina Amazon già aperta nel browser e non invia cookie o credenziali a Return Fixer.

Il debug redige query, token e identificatori sensibili prima di mostrarli.
